# Smart Room Environmental Controller

An Arduino UNO R4 WiFi project that monitors environmental conditions and automatically responds to them.

## Planned Features

- Temperature monitoring
- Light-level monitoring
- Automatic lighting
- Temperature-controlled fan
- LCD status display
- Automatic and manual operating modes
- Wi-Fi monitoring

## Hardware

- Arduino UNO R4 WiFi
- Arduino Starter Kit R4 components

## Project Status

Currently learning and testing the individual components required for the system.
